# CrackVision VQA reference documents

Place approved civil-infrastructure reference documents here as PDF, UTF-8 `.md`, or `.txt` files.

The first VQA implementation retrieves matching paragraphs using lightweight lexical matching. Keep source title, issuing organization, edition/date, and section headings in the document text so answers can cite them. Use references your team is permitted to store and use. The service does not treat these documents as a replacement for the governing standards or a qualified engineer's review.

PDF files are text-extracted with page references at upload time. Scanned PDFs need OCR before upload. The application provides local document administration and BM25 lexical retrieval; semantic embeddings are not currently used.
